# Student Management System

A full-stack web application built using Spring Boot, Thymeleaf, and MySQL that allows efficient management of student records and course enrollment. The project follows a layered architecture approach with clean separation of concerns, validation handling, authentication, and responsive UI design.

This project was developed for learning and practice purposes to strengthen concepts in backend development, MVC architecture, database integration, and Spring Security.

## Tech Stack

* Java (JDK 17/21)
* Spring Boot
* Spring MVC
* Thymeleaf
* Spring Data JPA (Hibernate)
* Spring Security
* MySQL
* Maven

## Key Features

* Student Management (Add, Update, Delete, View)
* Course Enrollment Functionality
* Form Validation using Spring Validation
* Pagination and Sorting Support
* Authentication and Authorization with Spring Security
* Exception Handling for Better Error Management
* DTO and Entity Layer Separation
* Responsive UI using Thymeleaf Templates
* Dashboard for Managing Student Data

## Project Highlights

* Follows clean layered architecture
* Uses JPA/Hibernate for database operations
* Secure login system implementation
* Organized and maintainable code structure
* Beginner-friendly real-world Spring Boot project

## Purpose

This project was created as a hands-on learning project to gain practical experience with full-stack Java development using the Spring ecosystem.
